# Biteaze Windows UI reference

Open **index.html** in a desktop browser to explore all 72 screens and popups. Use the bottom screen selector or click the app controls. No build, install or internet connection is needed.

- **Biteaze-Windows-UI-Reference.pdf** — visual design book (included in the ZIP).
- **guide.html** — readable implementation guide with links to every screen.
- **IMPLEMENTATION-GUIDE.md** — editable guide source: sizing, components, behavior and source mapping.
- **screens/** — 1920 × 1080 PNGs, plus continuations of long pages.
- **responsive/** — selected screens at 1366 × 768 and 1280 × 720.
- **screen-manifest.json** — numbered screen inventory and design rationale.
- **layout-validation.json** and **interaction-validation.json** — measured reference checks.
- **assets/** — local fonts, font licenses and Biteaze foundation tokens.

The reference is a visual prototype using sample data. Secondary forms/actions are representative. Nothing is connected to real payments, printers, customer data, messaging or production settings. Reload to restore the examples. Remove the dark design-explorer strip when implementing the app.

Primary target: 1920 × 1080. Secondary: 1366 × 768. Scaling check: 1280 × 720 effective pixels. Use the PDF at full width or zoom into the original PNGs for detail.
